QtRunner 
    策略交易程序的运行时启动器和组件协调者，不是具体的策略算法。
    它把 strategy_engine 中的引擎和策略管理器，与行情、交易、执行等模块连接起来。

    主要工作包括：

    读取配置，加载合约、商品、交易时段、节假日和主力合约等基础数据。
    根据 env.name 初始化 CTA、HFT 或 SEL 引擎。
    创建数据管理器、行情通道、交易通道、事件通知器和执行器，并配置路由规则。
    从配置加载启用的 CTA 或 HFT 策略，初始化策略参数并创建运行上下文。
    在 run() 中启动行情、交易和引擎；通常持续运行，直到收到退出信号。
